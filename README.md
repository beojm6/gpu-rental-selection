## 先算显存账：你的任务到底需要什么卡

显存需求由任务类型决定，这一步比比价格更靠前。可以按下面的下限来选：

- **模型测试、跑通流程**：中等显存（12–24GB）足够，7B 级别模型量化后可以运行
- **LoRA 微调**：32GB 显存是常见起点，7B–14B 模型会比较从容

## 从开机到跑通：最短部署路线

部署本身不复杂，四步能跑通推理服务：

1. **选区域**：服务对象在哪就选哪。面向国内和亚太用户选东京、新加坡、首尔，面向欧美选美东或法兰克福。
2. **装环境**：选 Ubuntu LTS 镜像，装好 NVIDIA 驱动和 CUDA，配合较新版本的 PyTorch。
3. **起服务**：`pip install vllm`，一条命令启动 OpenAI 兼容的 API 服务（指定端口 8000），业务系统直接按 OpenAI 接口格式对接，前端几乎不用改。
4. **做微调**：用 `peft` 加 `transformers` 跑 LoRA 训练，显存占用比全参数训练低一个量级，32GB 级显卡就能处理 7B 模型。

两个省钱技巧：推理速度不达标时，先上量化（4-bit、8-bit）和换推理框架，再考虑换卡；数据集大的话，把权重和数据留在本地盘，别每次开机重新拉取。
